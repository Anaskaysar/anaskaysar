## 🔬 Research Projects

### [MalariAI](https://github.com/Anaskaysar/MalariAI-Automated-Malaria-Cell-Segmentation-from-Blood-Smear-Images) — Label-Resilient Cell Segmentation
[![Demo](https://img.shields.io/badge/Live_Demo-HuggingFace-FFD21E?style=flat-square&logo=huggingface&logoColor=black)](https://huggingface.co/spaces/Kaysarulanas/MalariAI)
[![Paper](https://img.shields.io/badge/Manuscript-In_Preparation_(CMIG)-green?style=flat-square)](https://github.com/Anaskaysar/MalariAI-Automated-Malaria-Cell-Segmentation-from-Blood-Smear-Images)

A two-stage decoupled framework solving three persistent failure modes in malaria blood smear analysis.

| Stage | Method | Result |
|-------|--------|--------|
| Cell isolation | Distance-transform guided Watershed (annotation-agnostic) | **75.95% cell recovery** on NIH BBBC041 |
| Classification | EfficientNet-B0 + Focal Loss + Grad-CAM++ | **98.36% accuracy**, cross-validated on MP-IDB |

`Python` `PyTorch` `OpenCV` `EfficientNet` `HuggingFace`
